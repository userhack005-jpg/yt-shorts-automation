SilentVision

Personal YouTube Shorts uploader for the SilentVision channel.

SilentVision posts daily faceless Shorts about rare animals, human-body facts, and space. This app is a private Desktop uploader used only by the channel owner. It writes a short script, builds a vertical video, and uploads it to YouTube with the owner's Google account.

It requests YouTube upload, YouTube read, and YouTube Analytics read access so it can post Shorts and check channel progress. It does not sign in other people. It is not a public product.

Google user data is used only to upload videos to this one channel and to read that channel's stats. See the Privacy Policy.
